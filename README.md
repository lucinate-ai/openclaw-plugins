# OpenClaw Plugins

A collection of OpenClaw plugins built by the [Lucinate](https://lucinate.ai) project.

## Plugins

| Package | Description |
|---------|-------------|
| [file-list](packages/file-list/) | List directory contents via the OpenClaw tools HTTP API |

## Usage

Each plugin can be installed individually:

```bash
openclaw plugins install ./packages/file-list
```

Or published to ClawHub and installed from there.
